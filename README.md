
# 🐍 Sistema de Gestão de Notas de Alunos

Projeto desenvolvido em Python como atividade prática da disciplina **Linguagem de Programação**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

## 🎯 Objetivo

Desenvolver um sistema simples capaz de cadastrar notas, calcular a média do aluno, determinar sua situação e apresentar um relatório final.

## 🛠️ Tecnologias utilizadas

* Python
* Google Colab

## 📚 Conceitos utilizados

* Funções
* Listas
* Estrutura condicional `if` e `else`
* Estrutura de repetição `for`
* Estrutura de repetição `while`
* Entrada e saída de dados
* Validação de notas

## ⚙️ Funcionamento

O sistema permite que o usuário informe a quantidade de notas que deseja inserir.

As notas são armazenadas em uma lista e validadas para garantir que estejam entre **0 e 10**.

Depois, o sistema calcula a média e determina a situação do aluno:

* ✅ **Aprovado:** média maior ou igual a 7
* ❌ **Reprovado:** média menor que 7

Ao final, o sistema apresenta um relatório com as notas inseridas, a média calculada e a situação do aluno.

## 💻 Exemplo de resultado

```text
===== RELATÓRIO FINAL =====
Notas inseridas: [8.0, 7.0, 9.0]
Média: 8.00
Situação: Aprovado
```
